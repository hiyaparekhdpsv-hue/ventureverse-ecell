# VentureVerse 2026 🚀

A responsive event landing page designed for E-Cell BITS Pilani,
Hyderabad Campus.

## About

VentureVerse is a fictional entrepreneurship event concept created
for the E-Cell BITS Hyderabad event page design task.

The website focuses on creating a premium, futuristic and
startup-oriented visual identity while keeping the interface
simple and responsive.

## Features

- Responsive event landing page
- Hero section with event details
- Event highlights
- Interactive timeline
- Speaker section
- Registration CTA
- Scroll reveal animations
- Mobile responsive layout
- Interactive registration button

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Design Approach

The design uses a dark visual system with purple accents,
large typography, glassmorphism-inspired elements and generous
spacing to create a modern startup/event aesthetic.

The layout takes inspiration from contemporary entrepreneurship
and technology websites while using an original visual direction.

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any modern browser.
3. No installation or dependencies are required.
